# 20 Higgsfield Prompts — YouTube Shorts Pack

Two themes, ten each:
- **A. Cute animal rescues** (videos 1–10)
- **B. Ring doorbell / security cam moments** (videos 11–20)

Format conventions for every entry:
- **Higgsfield prompt** — paste into image-to-video or text-to-video. Keep aspect 9:16, 5–8s clip, 24fps.
- **Motion / camera** — Higgsfield motion control suggestion.
- **Title** — under 60 chars, hook-first.
- **Hook (0–2s on-screen text)** — stops the scroll.
- **Hashtags** — 4–6, mix of broad + niche.

Recommended Higgsfield settings across the pack: `Motion: Mix`, `Strength: Medium-High`, `Style: Cinematic Realism` (animals) or `Security Cam Realism` (doorbell). Add light grain + slight chromatic aberration on doorbell clips to read as "real footage."

## Production checklist (per video)

1. Generate base frame in Higgsfield image mode → refine until composition reads in the first 0.5s.
2. Image-to-video with the motion described, 5–8s.
3. Export 9:16, 1080×1920.
4. In editor: add bold sans-serif hook text in first 1.5s, captions, 1 sound effect, 1 trending audio track at low volume.
5. Upload as Short. Title + first comment with hashtags + pinned "Day X of…" style comment to push engagement.

## Posting cadence
- 2/day for 10 days, alternate themes (animal → doorbell → animal…) to balance the algorithm signal.
- Best windows (US): 7–9 AM and 7–10 PM local.
